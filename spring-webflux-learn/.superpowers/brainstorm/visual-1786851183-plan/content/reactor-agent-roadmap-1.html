面向 Agent 开发的 Reactor 学习路线

每节一个可直接运行的 main 示例；先观察日志与线程，再解释 API 和使用边界。

基础层：掌握流是什么

01 信号与订阅

onNext / onError / onComplete，冷流与热流，Mono / Flux。

02 变换与组合

map、flatMap、filter、concat、merge、zip、switchMap。

03 调度与上下文

delay、subscribeOn、publishOn、Scheduler、Context。

可靠性层：控制生命周期与压力

04 Disposable 与取消

订阅句柄、取消 Token 流、doFinally、usingWhen。

05 Sinks 与热事件

unicast、multicast、replay，推送工具进度与中间事件。

06 错误、超时与重试

onErrorResume、timeout、Retry.backoff、降级与幂等意识。

07 背压与限流

request、limitRate、buffer、drop、latest，防止慢客户端拖垮流。

Agent 应用层：将原理用于模型与工具

08 LLM Token 流

模拟流式输出、SSE 事件、用户取消与会话资源释放。

09 并发工具调用

flatMap 并发度、结果汇聚、顺序保证、超时隔离。

10 多 Agent 编排

Sinks 汇聚 Agent 事件，状态流、完成条件与错误传播。

11 Spring AI 落地

把 Token 流与工具流接入 WebFlux，形成可调用的 Agent API。

最终项目

实现一个具有流式回答、并发工具、取消、超时、背压保护与事件日志的迷你 Agent。
