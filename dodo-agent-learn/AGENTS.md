# dodo-agent-learn 开发规范

本文件中的规则适用于 `dodo-agent-learn` 目录及其全部子目录。

## 代码注释要求

- 今后在本项目中新增或修改代码时，必须为每一行有效代码添加中文注释，说明这一行代码的用途；空行不需要注释。
- 注释可以写在代码行上方，也可以在语言支持且不影响可读性的情况下写成行尾注释。
- `package`、类型声明、字段、构造方法、普通方法、条件分支、循环、异常处理、返回语句以及测试代码都属于需要注释的有效代码。
- 普通的 `import` 导入语句和注解可以不添加注释；如果某个自定义注解存在不直观的业务含义，仍应在相关类型或方法的说明中解释。
- Java、JavaScript、HTML、CSS、YAML 等项目内使用的代码或配置文件均遵守该要求；如果某种语法不适合行尾注释，应在对应代码之前添加独立注释。
- 重要逻辑必须添加清晰的块级注释，重点解释设计目的、执行步骤、数据流向以及为什么这样实现，不能只复述代码表面含义。
- 涉及 Agent 生命周期、流式响应、并发控制、任务取消、工具调用、上下文管理、异常处理和资源释放的逻辑，必须明确标注关键状态变化、边界条件和失败处理方式。
- 修改代码行为时必须同步更新相关注释，禁止保留与实际实现不一致的过期注释。
- 注释应以帮助学习和理解原理为目标，使用准确、具体、易懂的中文，避免只写“定义变量”“调用方法”之类没有额外信息的空泛描述。
