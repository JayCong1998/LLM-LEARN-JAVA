# 第 12 章：最终回答片段流

`/api/agent/chat/call` 保留一次性最终文本，供与新行为对照。 // 说明旧接口的保留目的。

`/api/agent/chat/stream` 是页面默认接口，最终回答会逐片段发出 `text` SSE 事件。 // 说明新接口与前端的连接关系。

工具调用、超时、重试、取消、并发和成功持久化仍由共享 ReAct 状态机处理。 // 说明两种 Agent 复用的运行生命周期。

只有流自然完成且聚合文本非空时才写入会话记忆和运行轨迹。 // 说明成功持久化边界。

模型流失败、取消和空流不会写入成功记录；持久化失败会在已发送片段后发送 `error` 与 `complete`。 // 说明流式失败可观察性与脏数据防护。

页面与轨迹都不保存或展示模型内部思维链。 // 重申安全边界。
