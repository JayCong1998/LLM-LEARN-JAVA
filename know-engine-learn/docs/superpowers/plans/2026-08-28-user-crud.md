# User 通用 CRUD 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 创建不继承 MyBatis-Plus 通用 Service 的 User 模块，并提供完整 REST CRUD。

**架构：** `UserMapper` 仅继承 `BaseMapper<User>`；`UserServiceImpl` 通过构造器组合 Mapper，直接调用 MyBatis-Plus Mapper API。Controller 使用独立请求 DTO 和统一响应结构，不接触 Mapper 或 Wrapper。

**技术栈：** Java 21、Spring Boot、MyBatis-Plus、Jakarta Validation、JUnit 5、Mockito
